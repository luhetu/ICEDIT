## 导师汇报建议：六页即可

1. **Problem: Remove the Target, Preserve the Others.** 展示旧 Coca-Cola 删除失败，标出新增招牌和受影响的可见内容。明确这是旧基座失败案例，不能证明所有强方法都失败。
2. **What We Have Built.** 展示 Instruction -> Contract -> Spatial Controls -> Editor -> Raw/Composite Evaluation。将尚未实现的干预模块画成虚线。
3. **What Existing Methods Already Solve.** 对照 ObjectClear、Consistency Critic 和 AdaEraser，说明各自覆盖目标/影响删除、参考修复和自适应抑制。
4. **Research Hypothesis.** 聚焦目标与保护对象交错、遮挡或影响重叠时的实例归属错误。用一个“删除 A、保留 B 及 B 的阴影”的例子解释。
5. **Controlled Pilot.** 展示 5 条件 x 3 固定种子；汇报当时真实任务状态。没有生成结果时，展示实验设计与已修复错误，不能画虚构数值图。
6. **Next Decision.** 强基线仍失败则推进归属感知控制；简单 mask 方法已经解决则调整研究方向。说明接下来两周的验证标准。

## 候选机制：实例归属指导的删除控制

以下是待验证方案，不是已经完成或已经确认新颖的方法。

输入除目标 T 外，显式记录受保护实例 P，以及关联影响和不确定区域 U。
例如移除一个人时，该人的阴影可删除，旁边另一个人的脸、衣服和阴影应保留。
单幅图不能保证唯一识别阴影归属或恢复被遮挡的真实背景，必须保留不确定性。

最小可检验设计：

1. 先对已有少量样例人工核验 T/P/U，建立诊断条件，不使用编辑后参考图生成可部署 mask。
2. 在同一去噪状态上，对目标参考证据和保护参考证据分别做受控开关，比较模型预测更新的响应。
3. 检查这些响应能否区分目标残留与保护对象受损，优于注意力大小、固定空间距离和普通 mask 扩张。
4. 只有响应确实具有区分能力，才实现按区域调节目标证据抑制和保护证据保留的模块。
5. 先用人工核验信息检验机制，再用 VLM/分割器预测信息，分别报告性能与额外输入成本。

注意：同状态响应也只是机制诊断，不能直接称为真实物理因果归属。
额外模型调用必须计入总成本，并与等计算量重采样进行比较。

## 如何判断这个方向值得继续

主结果应是删除完整性与保护损伤的权衡，而不是一个混合总分。

- 删除：目标是否消失、是否产生替代物、目标影响是否残留。
- 保护：可见保护区域差异、局部清晰度、文字保持、其他实例影响是否被误删。
- 重建：结构连续性、接缝与纹理自然度；未知背景不使用像素误差充当真值。
- 后处理：同时展示原始生成和融合后图像；保留所有固定种子。
- 公平性：相同图像和 mask 信息预算；额外保护标注必须给可兼容对照同样使用。

继续条件：强基线上问题重复出现；改进在未调参样例、多个种子及 raw 输出上成立；
普通 mask 扣除、膨胀、局部填充或等计算量重采样无法达到同样效果。
若只靠贴回源图就获得全部收益，应将其记录为工程后处理结果，重新寻找方法贡献。

## 可以直接说的开场白

我们目前将研究聚焦到对象删除中的选择性修改。现有方法已经可以删除物体及其阴影，
但当目标与其他实例紧邻或影响交错时，自然的输出不一定意味着修改正确。
我们希望研究怎样在删除指定实例的同时，减少对其他实例及其可见细节的误伤。
目前已经建立指令解析、空间控制和实验诊断链路，正在跑通专用删除基线。
下一步将先验证实例归属错误是否稳定存在，再决定是否采用生成过程中的证据干预机制。
